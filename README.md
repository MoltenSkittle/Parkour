# Parkour
Parkour is a game where you control a small, friendly green figure to traverse across platforms over deadly lava to reach what you crave: A gold coin at the end of the level. This is a game about movement and calculated precision, where even the tiniest slip can restart all progress on the level.

# How To Play:
When the game runs, you'll enter the main screen. Follow naturally and you'll get to the levels page where you can select which level you want to play. Most levels will be locked in the beginning. Simply click on one of the unlocked boxes - indicated with "INCOMPLETE" - to start to actually parkour.

W/Up Arrow to jump. A/Left Arrow to move left. D/Right Arrow to move right. Your goal is to jump from platform to platform to reach the gold coin at the end of each level. If you fall into the lava, you lose.

Want to pause the game? There's a little grey button at the top-right corner of the screen. You can restart, quit, or simply resume as you intend.

# How To Run:
(Windows only) At https://github.com/MoltenSkittle/Parkour/releases/tag/1.1, download the .exe file. Afterwards, run the .exe file, and the game will start up.

# Notes From Developer:
Although the levels screen displays five levels, only two are available! The rest will remain locked until added in the future.

# Why I Made This
I began working on this game to get a grasp on how basic platformer games work. I eventually want to work on a larger project focused on recreating a map of a 2D game I played in my childhood, with this project as part of the process.
