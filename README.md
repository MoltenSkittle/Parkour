# Parkour
Parkour is a game where you control a small, friendly green figure to traverse across platforms over deadly lava to reach what you crave: A gold coin at the end of the level. This is a game about movement and calculated precision, where even the tiniest slip can restart all progress on the level.

# How To Play:
W to jump. A to move left. D to move right. Your goal is to jump from platform to platform to reach the gold coin at the top of the level. If you fall into the lava, you lose.

# How To Run:
(Windows only) At https://github.com/MoltenSkittle/Parkour/releases/tag/1.0, download the .exe file. Afterwards, run the .exe file, and the game will start up.

# Notes From Developer:
This game isn't complete; it serves as a minimum-viable product. Choosing the 'Quit' option after dying in lava or reaching the coin doesn't do anything. Additionally, new levels haven't been added yet, so choosing the 'Next Level' option when reaching the coin doesn't do anything either.
